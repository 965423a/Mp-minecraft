# SMP + NUMA 多路 CPU 优化设计

> 目标:自研内核 + 服务器核心在任意多路拓扑(双路/四路/更多路)下,
> 自动适配、负载均衡、性能损耗最小。本设计为理论实现,
> 真机验证在双路服务器就位后进行。

## 1. 目标拓扑模型

- 机器 = N 个 NUMA 节点(node),每个 node 内含若干 CPU 核。
- 常见:N=2(双路)、N=4(四路),每 node 4~32 核。
- 内存访问代价不对称:访问本地 node 内存最快,跨 node 逐级变慢。
- 自适应要求:代码不得硬编码 node 数,一切从运行时拓扑探测出发。

## 2. 系统层(L1 内核)

### 2.1 拓扑探测(启动期)

- 从 ACPI SRAT 表读取:CPU → node 归属、内存 → node 归属。
- 从 MADT 表读取:APIC ID 列表(每核一个)。
- 构建核心数据结构:

```
struct Topology {
    nodes: Vec<Node>,            // 每 node:所属 CPU 列表、内存范围
    distance: Vec<Vec<u32>>,     // node 间相对距离矩阵(探测值/4)
    cpu_node: Vec<usize>,        // cpu -> node 映射
}
```

- 探测失败时降级:全部视为单 node(与现状一致,保证可移植)。

### 2.2 SMP 启动

- BSP(引导 CPU)通过 APIC 发 INIT-SIPI 序列唤醒全部 AP。
- 每个 AP 进入自己的 per-CPU 上下文(栈、TSS、就绪队列)。
- 启动顺序按 node 分组:先完成本 node 内存初始化再唤醒下一组,
  保证早期分配尽量 node-local。

### 2.3 调度器:per-CPU 就绪队列 + 工作窃取

- 每个 CPU 一个就绪队列(Chase-Lev 无锁 deque 原型):
  - push(bottom)/pop(bottom):本核操作,无锁;
  - steal(top):其他核操作,单一原子 CAS。
- **均衡规则(防"一核遇难众核围观")**:
  1. 本地优先:任务先入本核队列,本核 pop 优先。
  2. 空闲窃取:某核队列空时,先从**同 node 邻居**窃取;
     同 node 也空,再跨 node 窃取(取距离最近者)。
  3. 窃取带惩罚权重:跨 node 窃取到的任务,按距离降级其优先级,
     但仅当本地与同 node 均无任务时才发生。
- **NUMA 亲和**:
  - 任务标记首次执行所在 node(first-touch),此后该任务倾向在该 node 重放。
  - 周期性的负载统计:node 平均负载差异超过阈值才允许跨 node 迁移,
    避免高频跨 node 流量。
- **负载均衡度量(内核输出)**:每核完成任务数、窃取次数、
  跨 node 窃取次数、node 间负载方差;方差 > 阈值时内核告警。

### 2.4 NUMA 感知内存分配

- 页分配器按 node 分池:每个 node 一个空闲页列表,只管理本地内存。
- 分配策略:
  1. 默认 node-local(进程/线程所在 node);
  2. 本地耗尽才允许取相邻 node;
  3. 内核为服务器核心保留"内存镜像"选项(与 MC 协议无关,内核自身页表用)。
- 大页:2 MiB 大页优先用于世界区块缓冲(区块 98304 格 × 2 B ≈ 192 KiB,
  恰好可以页对齐多个区块,减少 TLB 压力)。
- **缓存行隔离**:per-CPU 队列头尾、计数器按 64 B 缓存行对齐,
  避免 false sharing。

## 3. 服务器核心(L3)的自适应分片

- 世界生成/更新任务按 **node 数分片**:
  ```
  node_id = hash(cx, cz) % node_count
  ```
  使每 node 负责近似等量的区块。
- 区块对象分配在归属 node 的本地内存(生成线程绑定该 node 的 CPU)。
- 同 node 内的 CPU 用工作窃取消化本 node 分片;node 间只在
  明显失衡时才借任务,借入任务执行期间不迁移回原 node。
- 玩家/实体更新按 player_id 或实体 ID 分到固定 node,保持状态局部性。

## 4. 性能损耗控制清单

| 项 | 措施 |
|---|---|
| 上下文切换 | 内核原语直接函数调用,不经过 syscall 陷阱 |
| 缓存 | 区块与热数据 cache-line 对齐;per-CPU 数据 64 B 隔离 |
| TLB | 2 MiB 大页覆盖区块缓冲 |
| 锁 | 调度无锁(CAS);文件/网络有锁但低竞争 |
| 迁移 | 跨 node 迁移有距离惩罚 + 失衡阈值 |
| 观测 | 每核/每 node 计数器,内核导出,Python 层可查 |

## 5. 验证方案

- 宿主机(单 node 8 逻辑核):`mc-sched` 原型模拟多 node 拓扑
  (把核划分成虚拟 node),验证:
  - 均衡性:各 node 完成任务数方差小;
  - 窃取路径:空闲核能拿到任务,无核空转围观;
  - 距离感知:同 node 窃取优先于跨 node。
- 真机(双路/四路):内核拓扑探测输出 vs `lscpu` 一致性校验,
  调度器负载均衡曲线,区块生成时间对比单路基线。

## 6. 现状对照(诚实基线)

- 当前应用层:标准库线程池 + 均匀分块(自适应 `available_parallelism`),
  无 node 感知——单 node 下正确,多 node 下未优化。
- 当前内核:单核引导,无 AP 启动、无调度器、无 NUMA 内存池。
- 本设计是这些缺失部分的蓝图;`mc-sched` 为调度/分片算法先行验证。
